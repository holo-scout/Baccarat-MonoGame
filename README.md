# Baccarat
A Baccarat card game developed using C#, .NET 10 and MonoGame, featuring animated card dealing, betting mechanics, chip management and visual roadmaps.

## Status
✅ Completed

## 📖 Overview
A desktop-based Baccarat game developed using C# and MonoGame, featuring an interactive casino-style interface, animated card dealing, and a functional betting system. The project implements core Baccarat gameplay mechanics alongside visual game elements, including betting zones, chip management, card animations, and score tracking.

Designed with modularity and reusability in mind, the project separates game logic, models, and card-shuffling algorithms into independent library projects, making the codebase easier to maintain, extend, and reuse.

## ✨ Features
- Baccarat Gameplay – Implements core Baccarat rules, including Player and Banker hands, card dealing, hand scoring, and round resolution.
- Interactive Betting System – Supports multiple betting zones, including Player, Banker, Tie, and pair bets.
- Chip Management – Allows players to place multiple chips across different betting areas, with automatic chip stacking and bankroll management.
- Animated Card Dealing – Features smooth card-dealing animations with realistic movement from the dealing shoe to designated card slots.
- Dynamic Game Interface – Includes a casino-style table layout, betting areas, chip selection dock, player balance display, and game controls.
- Roadmap Visualizations – Implements Baccarat scoreboards, including the Bead Plate and Big Road, using dynamically generated grid layouts.
- Reusable Shuffling Algorithms – Includes Perfect Riffle, Overhand, and Fisher-Yates shuffling algorithms.
- Event-Driven Architecture – Uses events to decouple game logic from UI components.
- Modular Project Structure – Separates game models, gameplay logic, and shuffling algorithms into reusable class libraries.
- Game State Management – Handles betting states, bankroll updates, round progression, and player bankruptcy scenarios.

## 🛠️ Technologies Used
- C# – Primary programming language.
- MonoGame Framework – Game development framework for rendering, input handling, and animations.
- .NET – Application runtime and class library development.
- Visual Studio – Development environment and project management.
- Git – Version control.
